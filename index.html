Om DigiBook

DigiBook er ein digital dagbok du kan dele med andre. Du kan skrive om tankane dine, finne andre som skriv om det same som deg, og svare, gje hjarte og følgje folk.

Ei skuleoppgåve

DigiBook er laga som Utviklingsprosjekt 1 i Utviklarfaget, 2IKTA, hausten 2026. Det er eit skuleprosjekt og ikkje ei ekte teneste, så ikkje del sensitive opplysningar her.

Bruk av KI

Eg har brukt Claude, ein KI-assistent frå Anthropic, i dette prosjektet. Claude har hjelpt meg med:

  • å skrive og forenkle koden (HTML, CSS og JavaScript)
  • å kople nettsida til Firebase og skrive sikkerheitsreglane
  • å finne og rette feil
  • design og fargar

Eg har sjølv bestemt idéen, kva funksjonar nettsida skal ha og korleis ho skal sjå ut. Eg har sett opp Firebase og GitHub, og testa nettsida saman med vennar.

Laga med

HTML, CSS og JavaScript · Firebase Authentication (innlogging) · Cloud Firestore (database) · GitHub (versjonskontroll)

Personvern

  • E-posten din ligg i ei privat mappe som berre du kan sjå.
  • Private tekstar kan berre du sjå.
  • Utkast og kveldsmodus vert berre lagra i nettlesaren din.
  • Du kan slette tekstane og svara dine når du vil.
